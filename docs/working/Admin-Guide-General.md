# Schedule a Membership Meeting
## Admin Guide — General

This guide is for anyone with admin access who handles day-to-day scheduling: managing elder availability, checking on appointments, and helping members and elders when something needs adjusting.

For technical setup, the Microsoft 365 sync, and troubleshooting, see the **Advanced Admin Guide** instead — you generally shouldn't need it for everyday tasks.

---

## 1. Logging In

1. Go to the scheduling website's `/manage` page (e.g., `elder.techfoundry360.com/manage` during testing; this will change to Coastal's own address after the migration).
2. Enter the shared admin PIN.

The PIN is shared among elders and admins. If you need the PIN or think it needs to be changed, talk to whoever holds Advanced Admin access.

---

## 2. Viewing and Managing Elder Availability

1. From the management screen, select an elder from the list.
2. You can view and edit that elder's available days and times on their behalf — useful if an elder calls or emails you a change instead of logging in themselves.
3. Save any changes.

**Note:** Elders can also log in and manage their own availability. You don't need to do this for every elder — only when they ask you to, or when they're not comfortable doing it themselves.

---

## 3. Viewing Appointments

1. From the management screen, look for the list of **upcoming appointments** (bookings members have made).
2. Each appointment shows the member, the elder, the campus, and the date/time.

Use this to answer questions like "did this person actually book a meeting?" or to spot-check that things are running smoothly.

---

## 4. Rescheduling or Canceling a Meeting

If a member or elder needs to change a booked meeting:

1. Find the appointment in the appointments list.
2. Update or cancel it as needed.
3. Let both the member and the elder know directly (by phone, text, or email) — don't assume they'll notice a change on their own, especially on short notice.

---

## 5. Campuses

The system currently supports eight campuses:

Battery Park · Bethany Campus · Chesapeake · Gloucester · Hampton · Mathews · Williamsburg · Yorktown

Each elder is tied to one campus. If an elder is showing up under the wrong campus, that's a data issue — pass it along to Advanced Admin rather than trying to fix it here, since campus is set automatically from our staff directory.

---

## 6. When to Escalate to Advanced Admin

Hand these off rather than troubleshooting yourself:

- An elder isn't showing up in the list at all (added or newly hired staff)
- An elder who left is still showing up as active
- Emails aren't being sent (confirmations, notifications)
- Anything involving the **"Refresh from M365"** button
- The PIN needs to be changed
- Anything that looks like a system error rather than a normal scheduling hiccup
